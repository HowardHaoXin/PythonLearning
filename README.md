# PythonLearning

> 一个用于记录 **Python 学习过程**的项目：`src/` 存放学习代码，`docs/` 存放对应的学习注解，两者一一对应，便于随时回顾查阅。

## 项目简介

本项目用于系统性地学习和复习 Python 基础语法，从零开始逐步推进。每个学习主题由两部分组成：

- **代码文件（`src/`）**：可运行的 Python 练习代码，含详细注释。
- **注解文档（`docs/`）**：对应该主题的知识点提炼、语法总结与易错点说明。

## 目录结构

```
PythonLearning/
├── src/           # Python 学习代码（BX_YYY.py）
├── docs/          # 学习注解文档（BX_YYY.md，中文命名）
├── README.md      # 项目说明
└── CHANGELOG.md   # 变更日志
```

## 文件命名规范

| 类型 | 规则 | 说明 |
| --- | --- | --- |
| 代码文件 | `BX_YYY.py` | `X` 为时间顺序编号，`YYY` 为学习内容（使用英文） |
| 注解文档 | `BX_YYY.md` | `X` 与对应 py 一致，`YYY` 统一用中文，便于一眼定位 |
