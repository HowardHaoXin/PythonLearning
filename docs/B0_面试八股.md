## 1. 变量与数据类型

> 对应 [B3_变量.md](B3_变量.md)

### Q1：Python 中 `is` 和 `==` 有什么区别？

**答案：** `==` 是比较运算符，判断两个对象的**值**是否相等；`is` 是身份运算符，判断两个对象是否指向**同一块内存地址**（即是否为同一个对象）。例如 `a = [1,2]`、`b = [1,2]` 时，`a == b` 为 `True`（值相等），但 `a is b` 为 `False`（两个不同对象）。对于整数、字符串等不可变对象，Python 可能复用已有对象，导致 `is` 结果具有缓存相关的特殊性。

### Q2：Python 中哪些类型是可变的，哪些是不可变的？为什么这很重要？

**答案：** 不可变类型有：整型 `int`、浮点型 `float`、布尔型 `bool`、复数 `complex`、字符串 `str`、元组 `tuple`；可变类型有：列表 `list`、字典 `dict`、集合 `set`。不可变意味着对象创建后其内容不能被修改，任何「修改」操作都会生成新对象；可变对象可以在原地修改内容。这一区别的重要性在于：不可变对象可作为字典的键或集合的元素（可哈希），且在多处引用时不会被意外改动，更安全。

### Q3：什么是小整数对象池（缓存）机制？

**答案：** Python 在启动时会预先创建 `-5` 到 `256` 之间的小整数对象并缓存起来。当程序引用这个范围内的整数时，不会创建新对象，而是直接复用缓存中已有的对象，因此 `a = 256; b = 256; a is b` 的结果为 `True`；而超出该范围的整数（如 `257`）每次会新建对象，`a is b` 为 `False`。这是基于 `is` 身份判断的常见面试陷阱。

### Q4：Python 是强类型还是弱类型？动态类型还是静态类型？

**答案：** Python 是**强类型**语言，即不同类型之间不会自动隐式转换（例如 `"1" + 1` 会抛出 `TypeError`，而不是自动转成 `"11"` 或 `2`）。同时 Python 是**动态类型**语言，变量的类型由赋值时确定，且可以随时改变，不需要事先声明类型。例如同一个变量可以先赋整数、再赋字符串。

### Q5：`None`、`0`、`False`、空字符串 `""` 有什么区别？

**答案：** `None` 是 `NoneType` 类型的唯一值，表示「没有数据」的空值；`0` 是整数类型的数值零；`False` 是布尔类型的假值；`""` 是长度为 0 的字符串。四者类型完全不同，`type(None)` 为 `NoneType`，`type(0)` 为 `int`，`type(False)` 为 `bool`，`type("")` 为 `str`。但在作为条件判断时，`0`、`False`、`""`、`None` 都会被判定为「假」（`False`）。

## 2. 字符串

> 对应 [B6_字符串.md](B6_字符串.md)

### Q6：为什么说字符串是不可变的？如果想要「修改」字符串，应该怎么做？

**答案：** 字符串是不可变对象，一旦创建，其内容就不能被原地修改。对字符串调用 `replace`、`upper`、`lower`、`strip` 等方法时，都不会改变原字符串，而是返回一个**新的字符串对象**。如果需要「修改」字符串，可以采用以下方式：一是将新结果重新赋值给变量，例如 `s = s.replace("a", "b")`；二是先转换为可变类型（如列表 `list(s)`）修改后再用 `"".join()` 拼回字符串。

### Q7：字符串用 `+` 拼接和用 `join()` 拼接，效率上有什么区别？

**答案：** 使用 `+` 拼接时，由于字符串不可变，每次拼接都会创建一个新的字符串对象并复制原有内容，在循环中进行大量拼接会产生大量中间对象，时间复杂度接近 O(n²)，效率低下。而 `join()` 会先计算总长度、一次性分配内存，再一次性拼接，效率远高于 `+`。因此拼接大量字符串时应优先使用 `"".join(可迭代对象)`。

### Q8：`find()` 和 `index()` 有什么区别？

**答案：** 两者都用于查找子串/字符并返回**首次出现**的索引。区别在于：`find()` 在未找到时返回 `-1`；`index()` 在未找到时抛出 `ValueError` 异常。因此在不能确定子串是否存在时，使用 `find()` 更安全。

### Q9：`encode()` 和 `decode()` 的作用是什么？什么是 UTF-8？

**答案：** `encode()` 用于将字符串（`str`）编码为字节串（`bytes`），`decode()` 用于将字节串解码为字符串。编码与解码必须使用一致的字符集，否则会出现乱码。UTF-8 是一种可变长度的 Unicode 字符编码方案，能表示所有 Unicode 字符，且对 ASCII 字符只占一个字节，兼容性好，是目前最通用的编码格式。

### Q10：如何反转一个字符串？

**答案：** 利用切片并设置步长为 `-1` 即可反转字符串，即 `s[::-1]`。切片语法 `str[start:stop:step]` 中，`step` 为负数时表示从后向前取值，`s[::-1]` 等价于从最后一个字符到第一个字符依次取出。

## 3. 列表

> 对应 [B7_列表.md](B7_列表.md)

### Q11：`append()` 和 `extend()` 有什么区别？

**答案：** `append(x)` 把参数 `x` 当作**一个整体元素**追加到列表末尾；`extend(iterable)` 把可迭代对象**拆开**，将其中的每个元素逐个追加到列表末尾。例如 `lst = [1,2]`，`lst.append([3,4])` 的结果是 `[1,2,[3,4]]`，而 `lst.extend([3,4])` 的结果是 `[1,2,3,4]`。

### Q12：列表和元组有什么区别？

**答案：** 主要区别有三点。一是**可变性**：列表可变，支持增删改；元组不可变，创建后不能修改元素。二是**语法**：列表用方括号 `[]` 包裹，元组用圆括号 `()` 包裹。三是**性能与应用**：元组由于不可变，内存占用更小、安全性更高，且可哈希，能作为字典的键或集合的元素；列表适合需要频繁增删改的场景。此外元组在元素唯一性上不限制重复，而不可变性使其更适用于表示固定的结构化数据。

### Q13：`sort()` 和 `sorted()` 有什么区别？

**答案：** `sort()` 是列表对象的**原地方法**，直接对原列表进行排序并返回 `None`；`sorted()` 是内置函数，接收任意可迭代对象，返回一个**新的排好序的列表**，不改变原对象。因此若需保留原顺序，应使用 `sorted()`；若无需保留，用 `sort()` 可节省内存。

### Q14：什么是深拷贝和浅拷贝？有什么区别？

**答案：** 浅拷贝（`copy.copy()` 或列表的 `[:]`、`list.copy()`）只复制对象的**最外层**，复制后新对象与旧对象的**内层可变子对象仍共享同一块内存**，修改内层子对象会互相影响。深拷贝（`copy.deepcopy()`）会**递归复制**对象的所有层级，创建完全独立的副本，修改任意层级都不会影响原对象。两者的根本区别在于：浅拷贝仅复制一层引用，深拷贝递归复制全部嵌套内容。

## 4. 元组

> 对应 [B8_元组.md](B8_元组.md)

### Q15：为什么元组是不可变的？不可变有什么意义？

**答案：** 元组被设计为不可变的数据容器，一旦创建就不能增、删、改元素。不可变的意义在于：一是**可哈希**，能作为字典的键或集合的元素；二是**安全**，作为只读数据被多处引用时不会被意外修改；三是**性能**，无需处理修改操作，内存占用与访问效率更优。适合存储如星期、坐标、常量等固定不变的数据。

### Q16：为什么单元素元组必须在元素后加逗号？

**答案：** 因为圆括号 `()` 在 Python 中既表示元组，也用于改变运算优先级。`(1)` 会被解释器当作普通括号，结果是整数 `1` 而非元组；只有写成 `(1,)` 才能被识别为包含一个元素的元组。因此单元素元组的正确写法是 `(元素,)`。

### Q17：元组中可以包含可变类型的元素吗？

**答案：** 可以。元组的「不可变」指的是元组**本身的结构**不可变，即不能改变它所持有的元素引用，但并不要求其元素本身不可变。例如 `t = (1, [2, 3])` 是合法的，元组内可以存放列表等可变对象；此时列表 `[2, 3]` 的内容仍然可以被修改，但元组不能更换、增加或删除这个列表元素。

## 5. 字典

> 对应 [B9_字典.md](B9_字典.md)

### Q18：字典的底层实现原理是什么？为什么查询时间复杂度是 O(1)？

**答案：** 字典底层基于**哈希表**实现。存储时，Python 先对键（key）计算哈希值，根据哈希值确定该键值对在哈希表中的存储位置；查询时同样对键计算哈希值，直接定位到存储位置取出值。由于定位是通过哈希计算直接完成的，与字典中元素的数量无关，因此字典的查找、插入、删除操作的平均时间复杂度为 **O(1)**。

### Q19：为什么字典的键（key）必须是不可变（可哈希）类型？

**答案：** 因为字典底层用键的哈希值来定位存储位置，键必须满足**可哈希**，即其哈希值在其生命周期内保持不变。可变对象（如列表）的内容可变，其哈希值会随之改变，会导致键无法被稳定定位、破坏哈希表结构，因此不能作为键。可哈希的要求等价于「不可变」，所以 `int`、`str`、`tuple`（且内部元素也可哈希）等可作为键，而 `list`、`dict`、`set` 不能。

### Q20：用 `dict[key]` 和 `get()` 取值有什么区别？

**答案：** `dict[key]` 直接取值，若键不存在会抛出 `KeyError` 异常；`get(key, default)` 取值时若键不存在则返回指定的默认值（默认为 `None`），不会抛出异常。因此在不确定键是否存在时，应优先使用 `get()` 以避免程序崩溃。

### Q21：Python 3.7 及以后的字典是有序的吗？

**答案：** 是的。自 Python 3.7 起，字典会**保持键值对的插入顺序**，遍历字典时按键被插入的先后顺序返回。这是语言层面的保证；而 Python 3.6 及更早版本的字典是无序的。需要注意的是，这里的「有序」指保持插入顺序，并非按键的大小排序。

## 6. 集合

> 对应 [B10_集合.md](B10_集合.md)

### Q22：集合有哪些特点？为什么能实现去重？

**答案：** 集合具有三个特点：**无序**、**无索引**、**元素唯一（无重复）**。去重的根本原因是集合底层同样基于哈希表，元素按哈希值存储，同一个元素（相同的值且可哈希）会映射到相同位置，因此重复的元素只会保留一份。此外集合支持交集、并集、差集等集合运算。

### Q23：`remove()` 和 `discard()` 有什么区别？

**答案：** 两者都用于删除指定元素，区别在于元素**不存在时**的行为：`remove(x)` 会抛出 `KeyError` 异常；`discard(x)` 则静默忽略、不会报错。因此在不关心元素是否存在时，使用 `discard()` 更安全。

## 7. 数据类型总结

> 对应 [B11_数据类型.md](B11_数据类型.md)

### Q24：请对比列表、元组、字典、集合四种容器（有序性、可变性、元素唯一性）。

**答案：**

| 类型 | 有序性 | 可变性 | 元素唯一性 |
| --- | --- | --- | --- |
| 列表 `list` | 有序 | 可增删改 | 元素可重复 |
| 元组 `tuple` | 有序 | 不可修改 | 元素可重复 |
| 字典 `dict` | 有序（保持插入序） | 可增删改 | 键唯一 |
| 集合 `set` | 无序 | 可增删 | 元素唯一 |

其中列表和元组通过索引/切片访问元素；字典通过键访问值；集合无索引、无键，主要用去重和集合运算。

### Q25：`del`、`len()`、`in` 这些公共操作分别有什么作用？

**答案：** `del` 用于删除变量或容器中的元素；`len()` 用于统计容器中元素的个数；`in` / `not in` 用于判断某个元素是否存在于容器中。此外还有 `sum()` 求和（仅对数值有效）、`max()` / `min()` 求最大/最小值等公共函数，它们对多种容器通用。

## 8. 运算符

> 对应 [B5_运算符.md](B5_运算符.md)

### Q26：`/` 和 `//` 有什么区别？`%` 的作用是什么？

**答案：** `/` 是真除法，结果**始终为浮点数**，例如 `5 / 2` 结果为 `2.5`；`//` 是向下取整除，结果为不大于真实商的整数，例如 `5 // 2` 为 `2`，`-5 // 2` 为 `-3`；`%` 是取余运算符，返回除法运算的余数，例如 `5 % 2` 为 `1`。`%` 常用于判断奇偶（`x % 2 == 0` 表示偶数）。

### Q27：Python 中运算符的优先级是怎样的？

**答案：** 算术运算符的优先级与数学运算一致，从高到低依次为：乘方 `**` ＞ 乘法、除法、取整除、取余 `* / // %` ＞ 加法、减法 `+ -`。同级运算按从左到右的顺序执行。当需要改变运算顺序时，使用圆括号 `()` 显式指定。

## 9. 条件与循环

> 对应 [B12_条件与循环.md](B12_条件与循环.md)

### Q28：`for` 循环和 `while` 循环有什么区别？分别适用什么场景？

**答案：** `for` 循环用于**遍历可迭代对象**（如字符串、列表、`range()` 生成的序列），循环次数由可迭代对象的元素个数决定，适合「已知要遍历多少内容」的场景。`while` 循环根据**条件是否成立**来决定是否继续循环，循环次数不预先确定，适合「满足某条件就持续执行」的场景。二者的共同点是：都需要确保循环能在某个时刻终止，避免死循环。

### Q29：`range()` 有哪几种用法？

**答案：** `range()` 用于生成整数序列，有三种用法：一是 `range(stop)`，生成 `0` 到 `stop-1` 的序列；二是 `range(start, stop)`，生成 `start` 到 `stop-1` 的序列，默认步长为 `1`；三是 `range(start, stop, step)`，生成 `start` 到 `stop-1`、步长为 `step` 的序列。注意 `range()` 的结果不包含 `stop` 本身，属于左闭右开区间。

### Q30：`break` 和 `continue` 有什么区别？

**答案：** `break` 用于**立即终止**整个循环，跳出循环体继续执行循环之后的语句；`continue` 用于**跳过本次循环**的剩余语句，直接进入下一次循环的条件判断/下一轮迭代。两者都只对当前所在的那一层循环生效。

## 10. 函数

> 对应 [B13_def.md](B13_def.md)

### Q31：`*args` 和 `**kwargs` 有什么区别？

**答案：** `*args` 用于接收**任意数量的位置参数**，在函数内部以**元组**的形式呈现；`**kwargs` 用于接收**任意数量的关键字参数**，在函数内部以**字典**的形式呈现。二者通常用于参数数量不确定的情况。在参数列表中，位置参数、默认参数、`*args`、`**kwargs` 的先后顺序一般为：位置参数 → 默认参数 → `*args` → `**kwargs`。

### Q32：使用可变对象作为默认参数会有什么问题？

**答案：** Python 中函数的默认参数在**函数定义时**就被创建并保存在函数对象中，多次调用会**复用同一个**默认对象。若默认参数是可变对象（如 `def f(x, lst=[])`），则每次调用若修改了 `lst`，修改会被保留到下一次调用，导致多次调用之间相互影响，产生难以察觉的 bug。因此默认参数应使用不可变对象（如 `None`），在函数内部再判断并创建可变对象。

### Q33：Python 函数的参数传递是值传递还是引用传递？

**答案：** Python 的参数传递既不是传统意义上的值传递，也不是引用传递，而是**传递对象的引用**（也称为「按对象引用传递」）。其表现是：当传入**不可变对象**（如整数、字符串）时，函数内部对参数重新赋值不会影响外部变量，行为类似值传递；当传入**可变对象**（如列表、字典）时，函数内部对对象内容的原地修改会反映到外部，行为类似引用传递。根本原因是不可变对象的「修改」会生成新对象并改变局部引用，而可变对象可以被原地修改。

### Q34：什么是形参和实参？

**答案：** **形参**是函数**定义时**写在括号里的参数名，用于在函数体内接收数据，如 `def greet(username)` 中的 `username`；**实参**是函数**调用时**传入的具体值，如 `greet("Howard")` 中的 `"Howard"`。调用时实参的数量和顺序应与形参保持一致（使用关键字参数调用时顺序可调整）。

### Q35：函数 `return` 返回多个值时，实际返回的是什么？

**答案：** 函数 `return` 后面写多个值（如 `return a, b`）时，Python 会将它们**打包成一个元组**返回。因此调用方可以用一个变量接收整个元组，也可以用多个变量进行解包接收（`x, y = f()`）。本质上多返回值就是返回一个元组。

## 11. 输入与输出

> 对应 [B4_FunInput.md](B4_FunInput.md)、[B2_FunPrint.md](B2_FunPrint.md)、[B1_Annotation.md](B1_注释.md)

### Q36：`input()` 函数的返回值是什么类型？如果输入数字要做运算该怎么办？

**答案：** `input()` 的返回值**始终是字符串类型（`str`）**，即使用户输入的是数字。如果需要将输入内容作为数字参与运算，必须先用类型转换函数进行转换，例如 `int(input(...))` 转为整数、`float(input(...))` 转为浮点数。若未转换直接相加，两个字符串会执行拼接而非数值相加（如 `"1" + "2"` 得到 `"12"`）。

### Q37：`print()` 的 `sep` 和 `end` 参数分别有什么作用？

**答案：** `sep` 参数用于指定**同一句 `print()` 中多个输出值之间的分隔符**，默认是一个空格；`end` 参数用于指定**输出结束后的结束符**，默认是换行符 `\n`（因此每次 `print()` 默认换行）。通过修改这两个参数，可以自定义多个值的分隔方式，以及控制是否换行、换行后追加什么字符。

### Q38：单行注释和多行注释分别怎么写？注释会被执行吗？

**答案：** 单行注释以 `#` 开头，其后的内容到行尾都是注释；多行注释用三个单引号 `'''...'''` 或三个双引号 `"""..."""` 包裹。注释是写给开发者看的说明文字，**解释器执行时会完全忽略**，不会对程序运行产生任何影响。注释的用途包括说明代码含义和临时禁用某些代码。
