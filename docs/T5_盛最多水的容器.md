# T5 盛最多水的容器

> LeetCode 第 11 题：双指针从两端向中间收，每轮移动「较矮」的那根线，O(n) 求出最大面积。

## 1. 题目

给定数组 `height`，选两条线与 x 轴构成容器，求能容纳的最大水量。面积 = `(right - left) * min(height[left], height[right])`。

## 2. 思路：双指针 + 贪心

1. 两根指针 `left`、`right` 从两端开始（此时宽度最大）。
2. 每轮算面积、更新最大值。
3. **移动「较矮」的那根线**。
4. 直到 `left >= right`。

## 3. 解法

```python
def maxArea(height):
    left, right = 0, len(height) - 1
    max_area = 0
    while left < right:
        area = (right - left) * min(height[left], height[right])
        max_area = max(max_area, area)
        if height[left] < height[right]:
            left += 1    # 左边矮，移动左指针
        else:
            right -= 1   # 右边矮（或相等），移动右指针
    return max_area
```

- **时间 O(n)**：两个指针一共移动 n 次。
- **空间 O(1)**。

## 4. 为什么移动「矮」的那根（关键）

面积由 `min(两高) × 宽度` 决定，而指针向中间收，**宽度只会越来越小**。

假设 `height[left] < height[right]`：若移动高的那根（`right` 左移），宽度变小，且 `min` 的上限仍是矮的 `height[left]`，面积不可能变大。所以唯一可能让面积增大的希望，是移动**矮**的那根，去碰碰看能不能遇到更高的线，把 `min` 抬高。这就是贪心策略的正确性。

## 5. 易错点

- 一定要移动**较矮**的那根，移反了就得不到正确答案。
- 面积用 `min(两高) × 宽度`，别用较高的那根算。
- 两高相等时移哪边都行（上面的写法统一 `right -= 1`）。
- `list[int]` 注解是 Python 3.9+ 语法，3.8 及以下会报错。
