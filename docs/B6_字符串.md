# B6 字符串（String）

> 字符串是「不可修改」的字符序列，支持索引、切片、运算和大量内建函数。

## 1. 字符串运算符

| 运算符 | 作用 | 示例 |
| --- | --- | --- |
| `+` | 拼接 | `"同志" + "你好呀！"` |
| `*` | 重复 | `"ab" * 3` → `"ababab"` |
| `in` / `not in` | 判断是否包含某字符 | `"你" in st1` |

## 2. 索引与切片

### 2.1 索引

- 正序：从左到右 `0, 1, 2, ...`
- 倒序：从右到左 `-1, -2, -3, ...`

```python
name = 'Harword'
name[0]    # 'H'
name[-1]   # 'd'
```

### 2.2 切片 `str[start:stop:step]`

截取一段内容，返回**新的字符串**（原串不变）。

| 参数 | 含义 | 默认 |
| --- | --- | --- |
| `start` | 起始索引（含） | 0 |
| `stop` | 结束索引（不含） | 末尾 |
| `step` | 步长 | 1 |

```python
name[:]       # 全部
name[2:]      # 从索引2到结尾
name[:5]      # 索引0到4
name[::2]     # 每隔一个取
name[::-1]    # 倒序（反转字符串）
```

## 3. 转义字符

以 `\` 开头，表示无法直接输入的特殊符号。

| 写法 | 含义 |
| --- | --- |
| `\t` | 制表符（Tab） |
| `\n` | 换行 |
| `\\` | 单个反斜杠 |
| `\'` / `\"` | 单/双引号 |
| `r"..."` | 原样输出，不转义（常用于路径） |

## 4. 格式化字符串（f-string）

在字符串前加 `f`，用 `{}` 包裹变量或表达式，比 `+` 拼接更清晰、更不易出错。

```python
age = 18
print(f"我的年龄是{age}")          # 基础
print(f"{age:2}")                 # 最小宽度 2
print(f"{age:02}")                # 最小宽度 2，不足补 0
print(f"{age:_>2}")               # 对齐：< 左对齐、> 右对齐、^ 居中
print(f"{3.14159:.10f}")          # 保留 10 位小数
```

## 5. 常用内建函数

### 5.1 查找类

| 函数 | 作用 |
| --- | --- |
| `find(x)` | 返回首次出现的索引，找不到返回 `-1` |
| `index(x)` | 返回首次出现的索引，找不到**报错** |
| `count(x)` | 统计出现次数 |

### 5.2 修改类（均返回新字符串，原串不变）

| 函数 | 作用 |
| --- | --- |
| `replace(old, new[, n])` | 替换（`n` 为替换次数） |
| `split([sep[, n]])` | 按分隔符分割，返回列表 |
| `join(iterable)` | 用分隔符把可迭代对象拼成字符串（`split` 的逆操作） |
| `strip()` | 去头尾空白字符 |
| `upper()` / `lower()` | 转大写 / 小写 |

```python
"-".join(["a", "b", "c"])   # "a-b-c"
"".join(["a", "b", "c"])    # "abc"
```

> 注意：`join` 是**分隔符**的方法，写法是 `分隔符.join(可迭代对象)`，不是 `列表.join(分隔符)`。拼接大量字符串时比 `+` 高效（见 B0 面试八股 Q7）。

### 5.3 判断类

| 函数 | 作用 |
| --- | --- |
| `startswith(x)` / `endswith(x)` | 是否以 x 开头 / 结尾 |
| `isupper()` / `islower()` | 是否全大写 / 全小写 |

### 5.4 编码与解码

```python
bytes_st = st.encode()   # 字符串 → 字节
bytes_st.decode()        # 字节 → 字符串
```

## 6. 易错点

- 字符串**不可变**：`replace`、`upper` 等不改变原串，需用新变量接收结果。
- 切片 `stop` 是**开区间**（不包含该索引）。
- `find` 找不到返回 `-1`，`index` 找不到抛异常，用前者更安全。
