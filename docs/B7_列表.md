# B7 列表（List）

> 列表是**有序、可修改**的数据容器，用 `[]` 包裹，元素用逗号隔开，可存放任意类型。

## 1. 认识列表

```python
list_string = ['a', 'b', 'c', 'd', 'e']
print(list_string, type(list_string), sep=", ")   # <class 'list'>
```

### 1.1 索引与切片（同字符串）

- 正序从 `0` 开始，倒序从 `-1` 开始。
- 切片语法 `list[start:stop:step]`，返回新列表。

```python
list_string[0]        # 'a'
list_string[-1]       # 'e'
list_string[1:3]      # ['b', 'c']
list_string[-1:-4:-2] # ['e', 'c']
```

### 1.2 可修改特性

```python
list_string[0] = 'A'   # 通过索引直接改值
```

## 2. 列表嵌套

列表里可以再放列表，用多级索引访问。

```python
grades = [[90, 80, 70], [80, 90, 80], [70, 80, 90]]
grades[0]       # [90, 80, 70]  子列表
grades[0][0]    # 90           子列表里的元素
```

## 3. 常见内建函数

### 3.1 添加元素

| 函数 | 作用 |
| --- | --- |
| `append(x)` | 末尾添加**一个**元素 |
| `extend(iterable)` | 末尾添加多个元素（把可迭代对象拆开逐一加入） |
| `insert(i, x)` | 在指定位置 `i` 插入元素 |

### 3.2 查找元素

| 函数 | 作用 |
| --- | --- |
| `index(x)` | 首次出现的索引，找不到报错 |
| `count(x)` | 统计出现次数 |

### 3.3 删除元素

| 函数 | 作用 |
| --- | --- |
| `remove(x)` | 删除首次出现的 `x`，不存在则报错 |

### 3.4 排序与反转

| 函数 | 作用 |
| --- | --- |
| `sort()` | 原地升序排序（`reverse=True` 降序） |
| `reverse()` | 原地反转 |

```python
lst = [3, 1, 2]
lst.sort()                 # [1, 2, 3]
lst.sort(reverse=True)     # [3, 2, 1]
lst.reverse()              # [2, 1, 3]
```

## 4. 易错点

- `append` 与 `extend` 区别：`append([1,2])` 把整个列表当**一个元素**放入；`extend([1,2])` 把 `1`、`2` 拆开逐个放入。
- `sort()` / `reverse()` 是**原地操作**，返回 `None`，不要写成 `lst = lst.sort()`。
- 列表可变，字符串、元组不可变。
