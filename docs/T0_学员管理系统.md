# B14 函数综合应用：学员管理系统

> 用函数把前面学到的知识（列表、字典、条件、循环、函数、input/print）综合成一个可运行的「学员管理系统」，是函数版完整项目。

## 1. 系统功能清单

1. 添加学员信息（学号、姓名、手机号，学号不可重复）
2. 删除学员信息（按学号）
3. 修改学员信息
4. 查询学员信息
5. 显示所有学员
6. 退出系统（二次确认，防止误操作）

## 2. 数据存储方式

采用「**列表 + 字典**」：

- 全局列表 `info` 存储所有学员，所有函数共用。
- 每个学员是一个字典：`{"id": 学号, "name": 姓名, "tel": 手机号}`。

```python
info = []   # 全局列表
```

## 3. 各功能函数

### 3.1 显示菜单 `show_menu()`

打印系统界面，提示可选的 1～6 号功能。

### 3.2 添加学员 `add_info()`

1. `input()` 获取学号、姓名、电话
2. 遍历 `info` 判断学号是否已存在，存在则提示并 `return` 结束函数
3. 组装成字典，`info.append(student_dict)` 存入列表

### 3.3 删除学员 `delete_info()`

- 按学号查找，找到后 `info.remove(student)` 删除，并打印被删信息，`return` 退出函数；否则提示「学员不存在」。

### 3.4 修改学员 `modify_info()`

- 找到学员后进入 `while True` 循环，让用户选择要改的字段（id/name/tel/none），输入 `none` 结束；修改后询问是否继续。

### 3.5 查找学员 `search_info()`

- 按学号查找并打印该学员信息，支持连续查找，输入 `n` 结束。

### 3.6 显示所有学员 `show_all_info()`

- 用 `\t` 对齐打印表头，遍历 `info` 逐行打印。

## 4. 主流程（框架）

```python
while True:
    show_menu()
    user_num = input("请输入功能对应序号(1-6)：")

    if user_num == "1":
        add_info()
    elif user_num == "2":
        delete_info()
    elif user_num == "3":
        modify_info()
    elif user_num == "4":
        search_info()
    elif user_num == "5":
        show_all_info()
    elif user_num == "6":
        exit_config = input("你确定要退出系统吗（y/n）？")
        if exit_config == "y":
            print("退出成功，欢迎下次再来！")
            break   # 终止循环，退出系统
    else:
        print("没有对应功能，请重新选择")
```

## 5. 设计要点小结

- **模块化**：每个功能一个函数，主流程用 `if/elif/else` 分发调用，结构清晰。
- **全局变量共享**：`info` 定义在函数外，所有函数读写同一份数据。
- **提前返回**：用 `return` 及时结束函数，避免继续执行后续逻辑。
- **容错与交互**：删除/退出都有二次确认，删除/查找/修改都对「学员不存在」做了提示。

## 6. 易错点

- `info` 是全局变量，在函数内**只读**没问题；若要**重新赋值**需用 `global` 声明（本系统用 `append`/`remove` 原地修改，无需声明）。
- 主流程用 `while True` + `break` 实现「循环菜单直到退出」。
- 学号按字符串（`input` 返回 `str`）比较，输入与存储类型要一致。
