# B8 元组（Tuple）

> 元组是**有序、不可修改**的数据容器，用 `()` 包裹，元素用逗号隔开。与列表的区别就在于「不可变」。

## 1. 认识元组

```python
tuple_chapter1 = (1, 2, 3, 4, 5, 6)
print(tuple_chapter1, type(tuple_chapter1), sep=", ")   # <class 'tuple'>
```

### 单元素元组的坑

只有一个元素时，**必须加逗号**，否则 `()` 会被当作普通括号，`(1)` 就是整数 `1` 而不是元组。

```python
t1 = (1)     # int，不是元组
t2 = (1,)    # 这才是元组
```

## 2. 索引与切片（同列表）

```python
tuple_chapter1[0]         # 1
tuple_chapter1[0:5:3]     # (1, 4)
tuple_chapter1[-1:-6:-3]  # (6, 3)
```

## 3. 特性：不可修改

元组一旦创建就不能增删改元素，这是它与列表**最本质的区别**。适合存放不希望被改动的数据（如星期、常量）。

## 4. 常见操作

```python
week = ('Monday', 'Tuesday', 'Wednesday', 'Thursday',
        'Friday', 'Saturday', 'Sunday')
```

| 操作 | 语法 | 说明 |
| --- | --- | --- |
| 成员判断 | `'Monday' in week` | 存在返回 `True` |
| 查找索引 | `week.index('Monday')` | 不存在会报错 |
| 统计次数 | `week.count('Monday')` | 不存在返回 `0` |

## 5. 易错点

- `(1)` 不是元组，`(1,)` 才是单元素元组。
- 元组不可修改，没有 `append`、`remove` 等方法。
- 元组比列表稍省内存、更安全，用于「只读」数据。
