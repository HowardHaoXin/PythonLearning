# B13 函数（def）

> 函数把一段可复用的代码「封装」起来，需要时调用即可，是代码复用和模块化的基础。

## 1. 定义与调用

```python
def greet():
    print("你好", "今天天气不错", sep='\n')

greet()   # 调用函数
```

语法：`def 函数名(参数):` 后接缩进函数体。

## 2. 带参数的函数

- **形参**：定义时写在括号里的参数（`username`）。
- **实参**：调用时传入的具体值（`"Howard"`）。
- 调用时参数的**数量与顺序**要与定义保持一致。

```python
def greet(username):       # username 是形参
    print(f"{username}你好")

greet("Howard")            # "Howard" 是实参
```

## 3. 默认参数

定义时给参数默认值，调用时可不传。

```python
def make_tee(tee_type='绿茶', sugar=1):
    print(f"泡一杯{tee_type},甜度{sugar}")

make_tee()          # 用默认值
```

## 4. 可变参数 `*args`

用 `*` 接收**任意数量**的位置参数，函数内部以**元组**形式接收。

```python
def sum_(*nums):
    num_sum = 0
    for n in nums:
        num_sum += n
    return num_sum

sum_(1, 2, 3, 4, 5)   # 15
```

## 5. 可变键值对参数 `**kwargs`

用 `**` 接收**任意数量**的关键字参数，函数内部以**字典**形式接收。

```python
def create_user(username, **user_info):
    print("用户名：", username)
    print("用户信息：", user_info)

create_user("Howard", age=18, sex="男", height=170)
# 用户信息： {'age': 18, 'sex': '男', 'height': 170}
```

## 6. 返回值 return

`return` 是函数的「输出」，把结果交回调用处；可以返回**多个值**（实际打包成元组）。

```python
def calc(a, b):
    return a + b, a * b

result = calc(1, 2)        # 方式1：接收为元组 (3, 2)
sum_, mul_ = calc(1, 2)    # 方式2：解包接收
```

## 7. 易错点

- 定义时用**形参**，调用时传**实参**。
- 位置参数、默认参数、`*args`、`**kwargs` 顺序为：位置参数 → 默认参数 → `*args` → `**kwargs`。
- `return` 会**立即结束**函数，后面的代码不再执行。
- 可变参数 `*args` 是元组，`**kwargs` 是字典。
