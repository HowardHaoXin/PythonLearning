# B12 条件语句与循环语句

> 让程序具备「判断」和「重复执行」的能力，是控制流程的两大核心。

## 一、条件语句

### 1. 简单 if 语句

满足条件就执行代码块（Python 用**缩进**表示代码块）。

```python
A = 11
if A % 2 == 0:
    print(f"{A}是偶数")
```

### 2. 比较运算符与逻辑运算符

**比较运算符：**

| 运算符 | 含义 |
| --- | --- |
| `==` | 等于 |
| `!=` | 不等于 |
| `>` / `<` | 大于 / 小于 |
| `>=` / `<=` | 大于等于 / 小于等于 |

**逻辑运算符：**

| 运算符 | 含义 |
| --- | --- |
| `and` | 并且（逻辑与） |
| `or` | 或者（逻辑或） |
| `not` | 非（逻辑非） |

> 注意：Python 中**非 0、非空**的数据当条件用时，都判定为 `True`。

```python
username, password = 'bingbing', '123456'
if username == 'bingbing' and password == '123456':
    print("登录成功")
else:
    print("登录失败")
```

### 3. 多分支判断 if / elif / else

```python
grade = 85.0
if grade >= 80.0:
    print("成绩优秀")
elif grade >= 60.0:
    print("成绩及格")
else:
    print("成绩不及格")
```

## 二、循环语句

### 1. while 循环

条件成立就一直循环，条件不成立才退出。

```python
count, count_sum = 1, 0
while count <= 5:
    count_sum += count
    count += 1
print(count_sum)   # 15
```

**while 嵌套：**

```python
cols = 1
while cols <= 3:
    rows = 1
    while rows <= 6:
        print(f'第{cols}排第{rows}列', end='  ')
        rows += 1
    cols += 1
    print('\n')
```

### 2. for 循环

`for 变量 in 可迭代对象/次数序列:`，用来遍历序列。

```python
for char in 'bingbing':
    print(char, end='  ')
```

### 3. range() —— 生成整数序列

| 写法 | 含义 |
| --- | --- |
| `range(stop)` | `[0, stop-1]` |
| `range(start, stop)` | `[start, stop-1]` |
| `range(start, stop, step)` | `[start, stop-1]`，步长 `step` |

```python
for index in range(10):
    ...
```

## 4. 易错点

- Python 靠**缩进**区分代码块，缩进不一致会报错或逻辑错乱。
- `while` 循环务必让条件**最终变为 False**，否则死循环。
- `range(stop)` 不含 `stop` 本身。
- `if` 判断相等用 `==`，赋值用 `=`，别混用。
