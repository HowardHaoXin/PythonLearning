# T1 两数之和

> LeetCode 第 1 题：用「哈希表（字典）」把暴力双循环的 O(n²) 降到 O(n)，是「空间换时间」的经典入门题。

## 1. 题目

给定整数数组 `nums` 和目标值 `target`，找出和为 `target` 的两个整数，返回它们的下标。假设每种输入**只有一个答案**，且**不能重复使用同一个元素**，返回顺序任意。

## 2. 解法一：暴力双循环（O(n²)）

思路：固定第一个数，再遍历它后面的数找配对的第二个数。

```python
def sum_twoSum(nums, target):
    for i in range(len(nums) - 1):
        for j in range(i + 1, len(nums)):
            if nums[i] + nums[j] == target:
                return [i, j]
```

- **时间 O(n²)**：两层循环。
- **空间 O(1)**：不额外开空间。

## 3. 解法二：哈希表（O(n)）—— 进阶

思路：一边遍历一边用字典记录「已看过的值 → 下标」，把「找配对数」从 O(n) 的遍历变成 O(1) 的查找。

```python
def sum_twoSum(nums, target):
    seen = {}                       # 存「值 -> 下标」
    for i in range(len(nums)):
        temp = target - nums[i]     # 当前数需要的互补值
        if temp in seen:            # O(1) 查找互补值是否已出现过
            return [seen[temp], i]
        seen[nums[i]] = i           # 记录当前值的位置
```

关键点：

- 用字典（哈希表）存「值 → 下标」。
- 对每个数，查 `target - 当前值` 是否已经出现过。
- **先查后存**，避免同一个元素用两次。
- 重复值也能正确处理（如 `[3,3]`：第一个 3 先存，第二个 3 查到它）。

- **时间 O(n)**：只遍历一遍，每次字典查找 O(1)。
- **空间 O(n)**：字典最坏存 n 个元素。

## 4. 两种解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| --- | --- | --- | --- |
| 暴力双循环 | O(n²) | O(1) | 简单直观，数据量大时很慢 |
| 哈希表 | O(n) | O(n) | 空间换时间，推荐 |

## 5. 易错点

- 字典存的是「**值 → 下标**」，查的是 `temp`（互补值），别搞反。
- 必须**先查后存**：先判断 `temp in seen`，再把当前值存进去；顺序反了就可能用同一个元素两次。
- 源码里用了 `dict = {}` 作变量名——`dict` 是内置类型名，虽然能运行，但会「遮蔽」内置函数，建议改成 `seen`、`num_map` 等更规范。
- 类型注解 `list[int]` 是 **Python 3.9+** 才支持的写法，3.8 及以下会报 `TypeError: 'type' object is not subscriptable`（升级到 3.12 即可）。
