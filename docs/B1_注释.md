# B1 注释（Annotation）

> 注释是写给「人」看的说明文字，解释器执行时会**完全忽略**它。用来解释代码、临时禁用代码，提高可读性和可维护性。

## 1. 单行注释 `#`

以 `#` 开头，其后内容即为注释，`#` 之后这一行剩余部分都不被执行。

```python
# 第一种：注释单独占一行（最常用）
print(123)

# 第二种：注释跟在代码后面
print(123)  # 输出 123
```

**作用：**
- 给某一行代码做说明
- 临时禁用某一行代码（调试时常用）

## 2. 多行注释 `''' ... '''`

用三个单引号 `'''`（或三个双引号 `"""`）包裹一段文字。

```python
'''
第一种写法：
注释内容
'''
'''第二种写法：注释内容'''
```

**作用：**
- 给一段代码、一个功能（函数、类）或整个文件做说明
- 临时禁用多行代码

## 3. 快速注释

- 快捷键：`Ctrl + /`，可快速注释 / 取消注释选中的代码。

## 易错点

| 写法 | 结果 |
| --- | --- |
| `# print(1)` | 被注释，不执行 |
| `print(1)  # 注释` | 只执行 `print(1)` |
| `'''注释'''` | 多行注释，不执行 |

- 注释不会影响程序运行，但**不是越多越好**：应注释「为什么这样做」，而非复述代码本身。
- 字符串里的 `#` 不是注释，例如 `print("#")` 会正常输出 `#`。
