# B9 字典（Dictionary）

> 字典存储「键值对（key:value）」，是**有序、键唯一、可增删改**的数据结构。键是唯一标识，值可为任意类型。

## 1. 认识字典

```python
person1 = {
    "姓名": "张三",
    "出生年月": "1990-01-01",
    "身份证号": "110101199001011234",
    "联系电话": "27404598753",
    "性别": "男"
}
```

- **键（key）唯一**，值（value）可以重复。

## 2. 常见操作

### 2.1 查找元素

```python
person1["姓名"]          # 方式1：字典[键]，键不存在会报错（不推荐）
person1.get("姓名")      # 方式2：get(键, default)，不存在返回 default（默认 None），推荐
```

### 2.2 添加 / 修改元素

```python
person1["学历"] = "本科"      # 键不存在 → 添加
person1["出生年月"] = "1990-02-26"   # 键已存在 → 修改
```

核心语法：`字典[键] = 值`，**键存在则改，不存在则增**。

### 2.3 删除元素

```python
person1.pop("学历")   # 删除指定键，返回被删除的值；键不存在且无默认值则报错
person2.clear()       # 清空所有键值对
```

### 2.4 其他操作

| 操作 | 作用 |
| --- | --- |
| `keys()` | 返回所有键 |
| `values()` | 返回所有值 |
| `items()` | 返回所有键值对 |

## 3. 易错点

- 取值优先用 `get()`，避免键不存在导致的 `KeyError`。
- `字典[键] = 值` 同时承担「添加」和「修改」两个功能。
- 空字典是 `{}`，与空集合 `set()` 不同。
