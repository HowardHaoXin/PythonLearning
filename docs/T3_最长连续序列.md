# T3 最长连续序列

> LeetCode 第 128 题：找出未排序数组中最长连续序列的长度。排序法 O(n log n) 简单直观，哈希集合法 O(n) 满足题目要求。

## 1. 题目

给定未排序的整数数组 `nums`，找出数字连续的最长序列的长度（不要求元素在原数组中连续），并要求 O(n) 时间复杂度。

## 2. 解法一：排序 + 去重（O(n log n)，本题实现）

思路：去重 → 排序 → 单次遍历，判断相邻差值是否为 1。

```python
def longestConsecutive(nums):
    if not nums:
        return 0
    nums = sorted(set(nums))            # 去重 + 排序
    max_len = 1
    count = 1
    for i in range(1, len(nums)):
        if nums[i] - nums[i - 1] == 1:  # 连续
            count += 1
        else:                           # 中断
            max_len = max(max_len, count)
            count = 1
    return max(max_len, count)          # 最后一段也要比较
```

- **时间 O(n log n)**：瓶颈在 `sorted`。
- **空间 O(n)**：`set` + 排序后的列表。

关键点：

- `set(nums)` 去重（连续序列里重复元素不增加长度）。
- 最后 `max(max_len, count)` 是为了处理「最长序列恰好是最后一段」的情况。

## 3. 解法二：哈希集合法（O(n)，题目要求）

思路：只从「连续序列的起点」开始向后数，避免重复计数。

```python
def longestConsecutive(nums):
    num_set = set(nums)
    longest = 0
    for num in num_set:
        if num - 1 not in num_set:      # num 是某个序列的起点
            cur, cur_len = num, 1
            while cur + 1 in num_set:   # 向后延伸
                cur += 1
                cur_len += 1
            longest = max(longest, cur_len)
    return longest
```

- **时间 O(n)**：每个元素最多被访问两次。
- **空间 O(n)**：`set`。

关键点：`num - 1 not in num_set` 保证只从序列起点开始计数，避免退化成 O(n²)。

## 4. 两种解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| --- | --- | --- | --- |
| 排序法 | O(n log n) | O(n) | 简单直观，n ≤ 10^5 时够用 |
| 哈希集合法 | O(n) | O(n) | 满足题目 O(n) 要求，最优 |

## 5. 易错点

- 别忘了**去重**：重复元素会干扰「相邻差值为 1」的判断（如 `[1,2,2,3]` 不去重会算错）。
- 空数组要返回 0（`if not nums: return 0`），否则 `sorted([])` 后仍取 `max_len = 1` 会出错。
- 排序法最后要 `max(max_len, count)`，否则「最长的是最后一段」时结果偏小。
- 哈希法里 `while` 延伸的起点必须满足 `num - 1 not in num_set`，否则退化成 O(n²)。
- `list[int]` 注解是 Python 3.9+ 语法，3.8 及以下会报错。
