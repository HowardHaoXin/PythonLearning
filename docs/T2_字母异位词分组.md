# T2 字母异位词分组

> LeetCode 第 49 题：字母异位词 = 组成字母及数量都相同的字符串。用一个「归一化的 key」把同组异位词映射到同一个字典键，即可完成分组。

## 1. 题目

给定字符串数组 `strs`，把**字母异位词**分组在一起，按任意顺序返回分组结果。

字母异位词：由相同字母组成、且每个字母出现次数都相同的字符串（重新排列可互相得到），如 `"eat"`、`"tea"`、`"ate"`。

## 2. 核心思路

给每个字符串算一个「归一化的 key」，让**同一组异位词得到相同的 key**，再用字典按 key 分组：

```
遍历每个字符串 s：
    key = 归一化(s)        # 异位词 → 同一个 key
    把 s 放进 dict[key] 对应的组

返回 list(dict.values())
```

## 3. 解法一：排序法（本题采用）

异位词排序后一定相同：`"eat"`、`"tea"`、`"ate"` 排序后都是 `"aet"`。把排序结果作为 key。

```python
def groupAnagrams(strs):
    groups = {}
    for s in strs:
        key = "".join(sorted(s))   # 排序后拼成字符串作为 key
        if key in groups:
            groups[key].append(s)
        else:
            groups[key] = [s]
    return list(groups.values())
```

关键点：

- `sorted(s)`：把字符串 `s` 拆成字符并按字母序排序，返回**列表**，如 `sorted("eat")` → `['a', 'e', 't']`。
- `"".join(sorted(s))`：把排序后的字符列表**拼回字符串**，得到 `"aet"`。
- 用这个字符串当字典 key，所有异位词都会落到同一个 key 下。
- `list(groups.values())`：取出所有分组。

- **时间 O(n·k log k)**：n 个字符串，每个排序 O(k log k)。
- **空间 O(n·k)**：字典存所有字符串。

## 4. 解法二：计数法（进阶，更快）

排序要 O(k log k)，改用「统计 26 个字母出现次数」作 key，可降到 O(k)。

```python
def groupAnagrams(strs):
    groups = {}
    for s in strs:
        key = [0] * 26
        for ch in s:
            key[ord(ch) - ord('a')] += 1
        key = tuple(key)          # 列表不能做字典键，转元组
        groups.setdefault(key, []).append(s)
    return list(groups.values())
```

- **时间 O(n·k)**：避免排序。
- **空间 O(n·k)**。

## 5. 两种解法对比

| 解法 | 时间 | 说明 |
| --- | --- | --- |
| 排序法 | O(n·k log k) | 代码最短，最好懂 |
| 计数法 | O(n·k) | 更快，推荐 |

## 6. 易错点

- 判断异位词要用「排序」或「计数」，**不能用 `set` 去重**——`set` 会丢失字母数量信息，把 `"aab"` 和 `"ab"` 误判成同类。
- `sorted(s)` 返回的是**列表**，要当字符串 key 得先 `"".join()`；或直接用元组 `tuple(sorted(s))`。
- 源码里用 `dict = {}` 作变量名，会**遮蔽内置的 `dict`**，建议改成 `groups`、`res` 等。
- `list[str]` 注解是 Python 3.9+ 语法，3.8 及以下会报错。
- 边界：空字符串 `""` 排序后是 `[]`，`"".join([])` 是 `""`，分组正常。
