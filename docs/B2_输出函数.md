# B2 输出函数 print

> `print()` 是 Python 最常用的内置函数，用于把内容输出到控制台。

## 1. 语法签名

```python
print(*args, sep=' ', end='\n', file=sys.stdout, flush=False)
```

常用的是前三个参数：`*args`、`sep`、`end`。

## 2. 参数详解

### 2.1 `*args` —— 想输出多少就输出多少

可以输出零个、一个或多个值，用逗号隔开。

```python
print()                              # 输出零个值（空行）
print("hello world")                 # 一个值
print("hello world", "hello world")  # 两个值
print(123, 456)                      # 两个数字
```

### 2.2 `sep` —— 分隔符

多个值之间的分隔字符，**默认为空格**。

```python
print("hello", "world", sep=", ")   # 输出：hello, world
```

### 2.3 `end` —— 结束符

输出结束后追加的字符，**默认为换行符 `\n`**。

```python
print("a", end="###")   # 输出 a###（不换行，接着输出后面的内容）
print("b", end="")      # 输出 b 后不换行、不加任何字符
```

## 3. 易错点

- `print` 每次调用默认**自动换行**（因为 `end='\n'`）。
- `sep` 只作用于**同一句 print 里的多个值之间**，不影响不同 print 之间。
- 参数可以用**关键字**传入（如 `sep=", "`），位置不能随意调换。
