# B11 数据类型总结

> 把前面学过的所有数据类型、公共操作和类型转换做一次总览，形成体系。

## 1. 数据类型分类

分为**基本数据类型**（单个数据）和**复合数据结构**（多个数据的集合）。

### 1.1 基本数据类型

| 类型 | 说明 |
| --- | --- |
| `int` | 整数，可计算，无小数点 |
| `float` | 浮点数，可计算，有小数点 |
| `bool` | 布尔，只有 `True` / `False` |
| `complex` | 复数，虚部带 `j` |
| `str` | 字符串，不可修改，支持索引/切片 |
| `None` | 空值，表示没有数据，单独类型 |

### 1.2 复合数据结构

| 类型 | 有序性 | 可变性 | 元素唯一 |
| --- | --- | --- | --- |
| `list` 列表 | 有序 | 可增删改 | 可重复 |
| `tuple` 元组 | 有序 | 不可修改 | 可重复 |
| `dict` 字典 | 有序 | 可增删改 | 键唯一 |
| `set` 集合 | 无序 | 可增删 | 元素唯一 |

## 2. 公共操作 & 公共方法

| 操作/方法 | 作用 |
| --- | --- |
| `in` / `not in` | 判断元素是否存在 |
| `len()` | 统计元素个数 |
| `del` | 删除变量 / 元素 |
| `sum()` | 求和（只对数值有效） |
| `max()` / `min()` | 求最大 / 最小值 |

## 3. 类型转换

| 函数 | 作用 |
| --- | --- |
| `int()` | 转整数 |
| `float()` | 转浮点数 |
| `bool()` | 转布尔值 |
| `str()` | 转字符串 |
| `eval()` | 执行字符串表达式并返回其值 |
| `list()` | 转列表 |
| `tuple()` | 转元组 |
| `dict()` | 转字典 |
| `set()` | 转集合 |

## 4. 记忆要点

- **可变 vs 不可变**：`list`、`dict`、`set` 可变；`tuple`、`str`、数值、`bool` 不可变。
- **有序 vs 无序**：`list`、`tuple`、`dict` 有序（可索引/按插入序）；`set` 无序。
- **元素唯一**：只有 `set` 去重、`dict` 键唯一。
