# B3 变量（variable）

> 变量是内存中用于存储数据的「命名空间」。通俗讲，就是给数据贴了个标签的快递盒：通过变量名就能取用、复用、修改数据。

## 1. 变量赋值

语法：`变量名 = 值`，其中 `=` 是**赋值运算符**（不是数学上的等号）。

```python
answer = 42        # answer 是变量名，42 是值
k = answer         # 把一个变量存的值赋给另一个变量
m = k + 1          # 支持表达式赋值
```

## 2. 变量的核心作用

1. **数据标识**：用名字代替数据本身
2. **数据复用**：多处使用同一数据
3. **动态修改**：可随时重新赋值

## 3. 变量的动态特性

Python 变量类型**不固定**，可随时赋不同类型的值（动态类型语言）。

```python
count = 2            # int
count = 3.14         # float
count = "hello"      # str
```

### 序列赋值（解包）

```python
count1, count2, count3 = 1, 2, 3   # 一一对应赋值
```

## 4. 变量命名

### 4.1 命名规则（硬性，违反会报错）

1. 只能包含字母、数字、下划线
2. 不能以数字开头
3. 不能使用 Python 关键字（如 `if`、`for`、`def`）
4. 严格区分大小写（`name` 和 `Name` 是两个变量）

### 4.2 命名建议（风格，为了可读性）

- **见名知义**：变量名应表达含义，如 `user_name`。
- 多单词命名方式：
  - 下划线分隔：`user_name`（Python 官方推荐）
  - 大驼峰：`UserName`
  - 小驼峰：`userName`

## 5. 基本数据类型（用 `type()` 查看）

| 类型 | 关键字 | 示例 | 说明 |
| --- | --- | --- | --- |
| 整型 | `int` | `123` | 无小数点 |
| 浮点型 | `float` | `3.14` | 有小数点 |
| 布尔型 | `bool` | `True` / `False` | 只有两个值 |
| 复数 | `complex` | `1 + 2j` | 虚部带 `j` |
| 字符串 | `str` | `'hello'` | 单/双/三引号包裹 |
| 空值 | `NoneType` | `None` | 表示「没有数据」 |

```python
print(type(123))       # <class 'int'>
print(type(None))      # <class 'NoneType'>
```

## 6. 易错点

- `None` 与 `0` 不同：`0` 是数值，`None` 表示空值/没有数据。
- 多行字符串用三对引号 `"""..."""` 包裹。
