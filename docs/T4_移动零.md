# T4 移动零

> LeetCode 第 283 题：用「双指针」把所有 0 移到末尾，同时保持非零元素的相对顺序，要求原地操作。

## 1. 题目

给定数组 `nums`，把所有 0 移到末尾，保持非零元素的相对顺序。必须**原地**操作（不能复制数组），且函数**不返回任何值**（Do not return anything, modify nums in-place instead）。

## 2. 思路：双指针（慢指针）

维护两个指针：

- `left`（慢指针）：指向「下一个非零元素应该放的位置」。
- `right`（快指针）：一路扫描整个数组。

`right` 每遇到一个非零元素，就把它和 `left` 处的元素交换，然后 `left` 右移。非零元素被依次「挤」到前面，0 自然沉到末尾。

## 3. 解法

```python
def moveZeroes(nums):
    left, right = 0, 0
    while right < len(nums):
        if nums[right] != 0:
            nums[left], nums[right] = nums[right], nums[left]   # 交换
            left += 1
        right += 1
```

- **时间 O(n)**：`right` 只扫一遍。
- **空间 O(1)**：只用了两个指针。

## 4. 为什么是「原地」

题目要求「不返回任何值、原地修改」。关键是不能写 `nums = ...`（那会让局部变量指向**新列表**，调用方的原列表不变），而要用**索引交换**直接改列表对象本身。上面 `nums[left], nums[right] = ...` 就是原地。

## 5. 易错点

- 不能 `return nums`，题目要求不返回任何值；测试时应先调用、再 `print(nums)`。
- 不能 `nums = [x for x in nums if x != 0] + ...`，这不是原地，原列表不会被修改。
- `left` 只在「发生交换」时才右移，`right` 每轮都右移——别把两个指针的移动规则搞混。
- `list[int]` 注解是 Python 3.9+ 语法，3.8 及以下会报错。
