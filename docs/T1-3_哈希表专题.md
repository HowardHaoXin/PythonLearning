# 哈希表专题总结

> T1 两数之和、T2 字母异位词分组、T3 最长连续序列 的最优解都用到了哈希表（`dict` / `set`）。本文整合三题，提炼哈希表的适用场景与使用技巧。

## 1. 为什么三题都用哈希表

哈希表（字典 `dict` / 集合 `set`）的核心优势是**平均 O(1) 的查找、插入、删除**。很多「看起来要两层循环 O(n²)」的问题，只要把内层循环的「遍历查找」换成「哈希表直接查」，就能降到 O(n)。

三题各自怎么用：

| 题目 | 哈希结构 | 用它做了什么 | 把什么变快了 |
| --- | --- | --- | --- |
| [T1 两数之和](T1_两数之和.md) | 字典 `dict` | 存「值 → 下标」，查互补值 | 找配对数 O(n²) → O(n) |
| [T2 字母异位词分组](T2_字母异位词分组.md) | 字典 `dict` | 归一化 key（排序/计数）→ 分组 | 分组归类 |
| [T3 最长连续序列](T3_最长连续序列.md) | 集合 `set` | 去重 + 判断 `num±1` 是否存在 | 序列延伸 O(n²) → O(n) |

## 2. 三题最优解回顾

### 2.1 T1 两数之和（字典：值 → 下标）

```python
def twoSum(nums, target):
    seen = {}
    for i, x in enumerate(nums):
        if target - x in seen:      # O(1) 查找互补值
            return [seen[target - x], i]
        seen[x] = i
```

### 2.2 T2 字母异位词分组（字典：归一化 key → 组）

```python
def groupAnagrams(strs):
    groups = {}
    for s in strs:
        key = "".join(sorted(s))    # 异位词 → 同一个 key
        groups.setdefault(key, []).append(s)
    return list(groups.values())
```

### 2.3 T3 最长连续序列（集合：存在性判断）

```python
def longestConsecutive(nums):
    num_set = set(nums)
    longest = 0
    for num in num_set:
        if num - 1 not in num_set:  # 只从序列起点延伸
            cur, cur_len = num, 1
            while cur + 1 in num_set:
                cur += 1
                cur_len += 1
            longest = max(longest, cur_len)
    return longest
```

## 3. 什么时候适合用哈希表

### 3.1 需要「快速查找 / 判断存在性」

要反复判断「某个值在不在集合里」时，用 `set`，O(1)。（T3）

### 3.2 需要建立「映射关系」

要记录「值 → 下标 / 计数 / 其他信息」时，用 `dict`。（T1 的「值 → 下标」）

### 3.3 需要「去重」

`set` 天然去重，且保留 O(1) 查找。（T3 去重）

### 3.4 需要「分组 / 归类」

把「属于同一类」的元素聚到一起，用一个「归一化 key」做字典键。（T2）

### 3.5 需要「以空间换时间」

凡是「两层循环 O(n²)，且内层是在找某个东西」的，考虑用哈希表把内层查找变 O(1)，整体降到 O(n)。（T1、T3）

## 4. 什么时候不适合 / 要慎用

1. **需要有序**：哈希表无序，若要求「遍历有序、找前驱/后继、第 k 大、区间」等，要用排序、二分、有序容器（如 `SortedList`）或树结构。
2. **键必须可哈希**：`list`、`dict`、`set` 等可变对象不能做字典的键（会报错）。
3. **数据量很小**：哈希表有常数开销，元素很少时未必比简单循环快。
4. **内存敏感**：哈希表以空间换时间，极端内存受限时需权衡。

## 5. dict 和 set 怎么选

| 需求 | 用哪个 |
| --- | --- |
| 只关心「在不在」 | `set` |
| 关心「值 → 某信息（下标/计数/列表）」 | `dict` |
| 统计出现次数 | `dict` 或 `collections.Counter` |

## 6. 一句话总结

> 当你发现自己在**重复地「查找某个东西」**（是否存在、对应什么值、属于哪一组）时，就考虑用哈希表：`set` 管「在不在」，`dict` 管「映射到啥」，用 O(1) 的查找把暴力 O(n²) 降成 O(n)。
