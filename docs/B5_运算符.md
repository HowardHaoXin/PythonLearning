# B5 运算符（Operator）

> 运算符用于对数据进行运算，分为算术运算符和赋值运算符两大类。

## 1. 算术运算符（数值的数学运算）

| 运算符 | 名称 | 示例 | 结果 |
| --- | --- | --- | --- |
| `+` | 加法 | `4 + 5` | `9` |
| `-` | 减法 | `4 - 5` | `-1` |
| `*` | 乘法 | `4 * 5` | `20` |
| `/` | 除法 | `4 / 5` | `0.8`（结果必为浮点数） |
| `//` | 向下取整除 | `4 // 5` | `0` |
| `%` | 取余 | `4 % 5` | `4` |
| `**` | 乘方 | `4 ** 5` | `1024`（前者底数，后者指数） |

**注意：**
- `/` 除法结果**一定是浮点数**。
- 运算值中只要含浮点数，结果就必为浮点数。
- 优先级与数学一致：`**` > `* / // %` > `+ -`，可用括号改变顺序。

## 2. 赋值运算符

### 2.1 简单赋值 `=`

```python
score = 98
```

### 2.2 复合赋值运算符（须先赋值才能用）

| 运算符 | 等价于 |
| --- | --- |
| `+=` | `x = x + n` |
| `-=` | `x = x - n` |
| `*=` | `x = x * n` |
| `/=` | `x = x / n` |
| `//=` | `x = x // n` |
| `%=` | `x = x % n` |
| `**=` | `x = x ** n` |

```python
score += 2   # 等价于 score = score + 2
```

## 3. 易错点

- `/` 与 `//` 区别：`5 / 2 = 2.5`（浮点），`5 // 2 = 2`（向下取整）。
- `%` 可用于判断奇偶：`x % 2 == 0` 为偶数。
- 复合赋值要求变量**已存在**，否则报 `NameError`。
