# B10 集合（Set）

> 集合是**无序、无索引、元素唯一（无重复）**的数据容器，用 `{}` 包裹，支持集合运算（交、并集等）。

## 1. 认识集合

```python
s = {1, 2, 3, 4, 5, 6, 1, 5, 4, 9}
print(s)   # {1, 2, 3, 4, 5, 6, 9}  重复元素被自动去重
```

**注意：** `{}` 是**空字典**，空集合要用 `set()`。

```python
data = {}      # 空字典 dict
data2 = set()  # 空集合 set
```

## 2. 常见内建函数

### 2.1 添加元素

| 函数 | 作用 |
| --- | --- |
| `add(x)` | 添加**一个**元素 |
| `update(iterable)` | 添加多个元素（可迭代对象） |

```python
s.add(7)
s.update([8, 9, 10])
```

### 2.2 删除元素

| 函数 | 作用 |
| --- | --- |
| `remove(x)` | 删除指定元素，不存在会**报错** |
| `discard(x)` | 删除指定元素，不存在**不报错**（推荐） |
| `clear()` | 清空集合 |

### 2.3 集合运算

```python
a = {1, 2, 3, 4, 5, 6}
b = {4, 5, 6, 7, 8, 9}
a & b                     # 交集 {4, 5, 6}
a.intersection(b)         # 交集（同上）
a | b                     # 并集 {1..9}
a.union(b)                # 并集（同上）
```

## 3. 易错点

- 集合**无序**，不能靠索引访问，也没有 `index()`。
- 元素自动**去重**，适合「去重」场景。
- `{}` 是空字典，不是空集合。
- 删除优先用 `discard()`，避免 `remove()` 因元素不存在而报错。
