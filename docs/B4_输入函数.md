# B4 输入函数 input

> `input()` 用于获取用户在控制台输入的数据，让程序能与用户交互。

## 1. 语法

```python
value = input(prompt)
```

- `prompt`：提示信息（字符串），显示在控制台，提示用户输入什么；默认为 `None`。
- `value`：返回值，即用户输入的内容。

```python
name = input("请输入你的名字：")
print(name, "你好呀！", sep=", ")
print(type(name))   # <class 'str'>
```

## 2. 关键特性

**`input()` 的返回值永远是字符串（`str`）类型**，即使输入的是数字。

## 3. 数据转换

因为返回值是 `str`，做数学运算前必须先转换类型。

```python
num_int1 = int(input("请输入一个整数："))   # 转整数
num_int2 = int(input("请输入一个整数："))
num_int = num_int1 + num_int2
print(num_int, type(num_int), sep=", ")
```

常见转换：`int()`、`float()`、`str()` 等。

## 4. 易错点

- **不转换就相加会出错**：`input()` 返回 `"1"`，`"1" + "2"` 结果是字符串 `"12"` 而不是数字 `3`。
- 转换时若输入无法解析的内容（如 `int("abc")`）会抛 `ValueError`。
